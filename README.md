# A Letter for Flowee 🌸

An interactive apology and romantic love letter page created with love.

## ✨ Features
- Atmospheric romantic background & music support
- Interactive envelope opening experience
- Sincere apology letter with interactive photo memories
- "Will you forgive me?" dynamic buttons with playful evasive "No" button
- Confetti celebration upon forgiveness

## 🌐 Live Preview
Can be hosted easily via **GitHub Pages**:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment** > **Branch**, select `main` and root `/`
3. Save and access via `https://bima204.github.io/apologize/`
